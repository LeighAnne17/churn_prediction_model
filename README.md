# 🧠 Customer Churn Prediction & Segmentation Project
This project applies data analytics and machine learning to predict customer churn and segment users for strategic business insight.

---

## 🔍 Problem Statement
Companies lose revenue when customers churn unexpectedly. The goal is to predict churn based on customer behavior and to identify distinct customer segments for marketing or retention purposes.

---

## 📦 Tools & Libraries
- Python (pandas, matplotlib, seaborn, scikit-learn, joblib)
- Jupyter Notebooks
- Visual Studio Code

---

## 🛠️ Key Features
- Cleaned and transformed raw customer data
- Built Random Forest model to predict churn (ROC AUC: 0.64+)
- Tuned model using GridSearchCV
- Evaluated using classification metrics and ROC Curve
- Segmented customers using K-Means clustering
- Visualized patterns and exported performance graphs

---

## 📈 Model Performance
- ROC AUC Score: **0.64** (baseline)
